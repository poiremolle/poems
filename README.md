# poems
A poem creator that generates poems according to dates.

# 2026 update
Back in 2020 I decided to go back to school. I wanted to study software engineering, but I was missing a ton of high school prerequisites. I went back to high school and while I was doing that, I decided to start learning programming on the side to get a head start. I started with the creative coding library p5.js and tutorials from [The Coding Train](https://thecodingtrain.com/).

I tried to leave this project as intact as possible, but I just wanted to fish out the index.html and put it in the root so that github pages would serve it automatically. I still like the outcome of this project a lot. Even though the result the code is generating is static, I guess I felt like I was digging into the collaboration between humans and machines in the art-making process. There's definitely a more organic and imperfect quality to the poems of my poem generator, rather than asking a chatbot to write one. I like the delight in finding a touching poem at a random date.
